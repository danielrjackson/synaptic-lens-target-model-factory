# Synaptic Lens Target Model Factory

Target-network recipes for [Synaptic Lens](https://github.com/danielrjackson/synaptic-lens), developed by Daniel Jackson with AI-assisted engineering and curation.

This initial commit establishes attribution and unmodified research-use RAIL-S/M
license files. It contains no executable recipe, model checkpoint or dataset.
Curated source will enter through a separately reviewed pull request after the
repository bootstrap is approved. Dataset and dependency rights remain separate.

See [NOTICE](NOTICE), [LICENSE.md](LICENSE.md), [LICENSE-MODEL.md](LICENSE-MODEL.md)
and [CITATION.cff](CITATION.cff). Model terms apply only to models expressly
identified by a release; no models are distributed by this initial commit.
